# Raw Data CSVs (Plonky2 vs Nova)

## Files
- `basic_plonky2.csv`: Basic (non-recursive) matrix multiplication measurements for Plonky2.
- `basic_nova.csv`: Basic matrix multiplication measurements for Nova 
- `recursive_plonky2.csv`: Recursive matrix multiplication measurements for Plonky2.
- `recursive_nova.csv`: Recursive matrix multiplication measurements for Nova.

## Units
- Time is in microseconds (`*_us`).
- Proof size is in kilobytes (`*_kb`).
- Memory is in gigabytes (`*_gb`).
